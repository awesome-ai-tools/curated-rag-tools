# Contributing to Curated RAG Tools

Thank you for your interest in contributing! This guide will help you add new tools or improve existing entries.

## How to Add a New Tool

1. **Fork** this repository
2. **Create a branch** for your addition: `git checkout -b add-tool-name`
3. **Add your entry** in the appropriate category section of `README.md`
4. **Submit a pull request** with a clear description

## Entry Format

Each tool entry should follow this table format:

```markdown
| **Tool Name** | Brief, factual description of what the tool does and its key features. | [GitHub](https://github.com/org/repo) &#124; [Docs](https://docs.example.com/) |
```

## Requirements for New Entries

### Must Have
- [ ] The tool is **actively maintained** (commits within the last 12 months)
- [ ] The tool is **directly relevant** to RAG (Retrieval-Augmented Generation)
- [ ] Description is **accurate and concise** (1-2 sentences)
- [ ] All links are **working and point to official resources**
- [ ] Entry is placed in the **correct category**
- [ ] Entry is added in **alphabetical order** within its category

### Must Not
- [ ] No duplicate entries (check existing list first)
- [ ] No promotional or marketing language
- [ ] No tools that are abandoned or archived
- [ ] No paid-only tools without a free tier or open-source version (exceptions for RAG-as-a-Service category)

## Categories

- **RAG Frameworks** -- End-to-end frameworks for building RAG pipelines
- **Vector Databases** -- Databases for storing and querying vector embeddings
- **Embedding Models** -- Models for generating vector embeddings
- **Document Loaders & Parsers** -- Tools for ingesting and parsing documents
- **Chunking & Preprocessing** -- Libraries for splitting text into chunks
- **Retrieval & Reranking** -- Models and tools for improving retrieval accuracy
- **Evaluation** -- Frameworks for measuring RAG pipeline quality
- **RAG-as-a-Service** -- Managed platforms for deploying RAG systems

## Suggesting a New Category

If your tool does not fit any existing category, open an issue to discuss adding a new one before submitting a PR.

## Updating Existing Entries

If you notice outdated information, broken links, or inaccurate descriptions:

1. Open an issue describing the problem, or
2. Submit a PR with the correction

## Code of Conduct

- Be respectful and constructive
- Focus on factual, objective descriptions
- Avoid self-promotion or biased language
- Help maintain the quality of this curated list

## Questions?

Open an issue if you have questions about whether a tool qualifies or which category it belongs in.
